# Contributing

## Running locally

- `bun install`
- `bun dev`
- `bun run check` runs typecheck, lint, and a production build. It must pass before you open a PR.

## Conventions

- One commit per change. Each commit should be a single, self-contained change.
- No code comments. Do not add `//`, `/* */`, JSDoc, or JSX comments anywhere in the codebase.
- Do not change visual behavior or page markup unless the change is explicitly about that.

## No AI-generated contributions

Pull requests, issues, and code produced in whole or in part by AI coding assistants or LLMs are not accepted. You must confirm in the PR that no AI tooling authored the change. Maintainers may close PRs that appear AI-generated without review.
